# React Native learning videos

Goal: learn enough JavaScript, React, React Native, Expo, and Supabase to understand and make small changes to this app's code, even when AI writes much of it. The goal is not to master every topic before starting.

## Order

1. **JavaScript preparation video (~28 minutes)** — The video beginning "hey guys how's it going ... every single thing you need to know in JavaScript ... before React." It covers arrow functions, conditional expressions, object destructuring, the spread operator, `.map()`, and `.filter()`. Useful for reading React code. It assumes basic JavaScript and only points to promises, `async`/`await`, and `fetch` as further topics. Transcript attachment: `b775c598-39d7-4022-9f73-c1088eb3bef3`.

2. **Code with Beto beginner React Native video (~68 minutes)** — Builds a Pokédex with Expo. Explains what React Native and Expo do, then introduces components, styling, `useState`, `useEffect`, API fetching, lists, and Expo Router. This is the best first hands-on React Native video of the ones reviewed. It says no React background is required, but its coding section moves quickly, especially around 27–35 minutes. Transcript attachment: `0987164c-ab3b-41a1-8851-d91b351ffced`.

3. **Long Expo/React Native/Supabase course (~5 hours 18 minutes)** — Builds a BeReal-like photo-sharing app. Covers Expo project structure and device testing, React Native UI, Expo Router, authentication, Supabase tables and row-level security, image storage, session handling, and an overview of EAS. Best for seeing how the planned stack fits together in a real app. It explains React Native features as it goes but does **not** teach React syntax and concepts from scratch. Its Supabase security explanation is brief. Transcript attachment: `fdcd2509-b603-456f-a6b5-5288c4ce444c`.
