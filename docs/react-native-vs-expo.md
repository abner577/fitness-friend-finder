## React Native
- React Native is what lets you write a mobile app with React. Expo is a set of tools that makes building, testing, and releasing that React Native app easier.

- In a React website, you write componenets that become browser elements such as <div> and <p>. In React Native, you use the same React ideas, componenets, state, and JS or TS but write mobile componenets such as <View> and <Text>.

- The programming pattern is familiar if you know React.

## Expo
- Expo gives you a ready-made way to create and run the project, it also provides packages for common phone features, such as the camera, location, and contact. Its build service can turn the project into seperate installable Android and iOS apps for testing or store submission.

- Expo is to React Native roughly what Next.js is to React for the web. Its an optional framework that gives you a more complete starting point and a set of tools that work together.
