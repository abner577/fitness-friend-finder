# Fitness Friend Finder notes

These files collect the idea for an app that helps people find friends to do fitness activities with. They are notes for thinking and planning. Nothing here means the app is being built yet.

- [The app idea](docs/app-idea.md) — the problem, who the app is for, and a simple example of using it.
- [Features and ideas](docs/features.md) — first version features and all later feature ideas.
- [How location could work](docs/location.md) — a plain answer to the question about finding people nearby.
- [Decisions and ideas](docs/decisions-and-ideas.md) — what we have chosen, what is only a suggestion, and open questions.

The decisions file is the place to check what has actually been agreed. The other files describe how those choices might feel in the app.
